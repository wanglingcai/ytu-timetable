# 下节啥课 0.9.4

发布日期：2026-10-29

## 更新内容

- 课表区域支持左右滑动切换上一周和下一周，不必只点击顶部箭头；上下滑动仍用于页面滚动，课程卡片和空白格点击保持可用。
- 优化启动渲染流程，先读取本地课表并完成首帧渲染，再显示页面，避免打开应用时短暂闪现“导入课表”初始界面。
- 完善学校适配器结构、烟台大学配置和标准课程数据输出。
- 增加网页读取与接口读取的一致性校验、单双周校验、域名白名单校验和页面改版错误提示。
- 保留 Excel、CSV、TSV、HTML 和 JSON 备份导入作为通用兜底方式。

## 验证

- Node 核心测试：29 项通过。
- Playwright 页面测试：14 项通过。
- Android 15 模拟器：33 项完整流程检查通过。
- Release APK 使用项目现有 release keystore 签名，并提供 SHA-256 校验值。

## 已知限制

- 烟台大学官网读取仍需要校园网或学校 VPN，登录和验证码需要用户自行完成。
- 其他高校需要单独添加学校适配器；未适配学校可以使用通用文件导入。
