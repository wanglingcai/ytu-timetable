# 下节啥课

一个简洁、免费、公开源码的 Android 课表应用。它把课表保存在手机本地，打开就能查看下一节课、周视图和个人安排，也支持到点提醒、完整备份和自定义背景。

当前源码版本：**0.9.1（versionCode 20）**。项目最初为烟台大学使用，应用名称从“烟大随课”改为“下节啥课”，现在同时支持通用表格导入，并持续适配其他高校的教务平台。

## 为什么做这个项目

很多课表应用把查看课表和广告、会员或账号体系绑定在一起。对只想快速确认“下一节是什么课”的学生来说，这些干扰很烦，也让自己的课程数据必须交给第三方服务。

所以我做了一个更直接的选择：

- 不放广告，不要求充值，不自建账号和服务器；
- 课表、个人安排、提醒和背景都保存在手机本地；
- 查看已保存课表不需要登录或联网；
- 代码、构建方式和限制公开，方便自己检查，也方便其他同学一起改进。

这是一个个人公开源码项目，不是学校官方应用。欢迎把它当作一个可自由使用和共同维护的课表工具。

## 主要功能

- **下一节课**：显示最近或正在进行的课程、地点、时间和倒计时。
- **周视图**：左右切换周次；当前周使用淡彩课程卡片，其他周的课程以灰色显示作为参考。
- **个人安排**：点击空白课时添加自习、运动、会议或待办，支持地点、备注、重复周次和修改删除。
- **多种导入方式**：支持 .xlsx、.xls、.csv、.tsv、.html、.htm 和本应用 .json 完整备份。
- **烟台大学官网登录读取（测试）**：从统一身份认证进入 eHall 和本科教务系统，登录后读取“选课结果”，再由用户核对并保存。
- **导入变化对比**：再次导入时显示新增、删除和调整的课程，确认后才替换原课表。
- **到点提醒**：课程和个人安排可以分别设置提醒时间，支持安卓通知和精确提醒权限。
- **完整备份**：导出和恢复课表、个人安排、提醒、学期设置、外观参数和背景图。
- **清爽界面**：连续细网格、淡彩课程、空白格透出背景图、周次切换和底部快捷操作栏。
- **自定义外观**：从本地选择背景图，调节白色遮罩和模糊程度；图片不会上传。
- **桌面小组件（0.9.1）**：在安卓桌面显示下一节课程的名称、时间、地点和倒计时，点击组件可打开应用。

## 安装和快速使用

1. 从 [GitHub Releases](https://github.com/wanglingcai/ytu-timetable/releases) 下载最新 APK，安装到 Android 8.0 或更高版本的手机。正式包会附带 SHA256SUMS.txt，可用来校验下载文件。
2. 第一次打开时，可以点击“先体验示例课表”，也可以直接点击“导入”。
3. 选择课表文件或完整备份，在导入预览中核对课程名称、教师、地点、节次和周次。
4. 填写学期名称、**第一周周一的日期**和学期总周数，勾选确认后保存。
5. 以后打开应用即可离线查看。用左右箭头或周次菜单浏览其他周，点击“回到本周”返回当前周。

首次使用建议先确认第一周日期和作息时间。应用默认使用烟台大学页面常见的节次时间，可在设置中修改。

### 签名与升级

正式 APK 通过 GitHub Releases 分发，并附带 SHA-256 校验文件。0.8.3 及后续正式版本使用同一个 release keystore，可以直接覆盖升级。0.6.3 及更早版本是 debug 签名包；从 debug 包切换到正式包时，请先在应用内导出完整 JSON 备份，再卸载旧版、安装新版并导入备份。

## 界面怎么用

| 位置 | 用法 |
| --- | --- |
| 顶部“接下来” | 查看最近一节课或个人安排，点击可定位到实际日期所在周。 |
| 周次切换栏 | 左右切换周次，点击“回到本周”返回当前周。 |
| 课表网格 | 点击课程查看详情；点击空白格直接添加个人安排。灰色课程表示它不在当前所选周上课。 |
| 底部“全部安排” | 查看其他周的个人安排和课程列表。 |
| 底部“＋ 添加” | 添加个人安排，或打开文件、备份和官网导入入口。 |
| 右上角齿轮 | 设置学期、节次、提醒、背景图和通知权限。 |

### 添加个人安排

在目标周点击空白格，填写名称、地点和备注，选择“仅本周”“每周”或自定义周次后保存。已有安排可以点击卡片修改或删除。个人安排会包含在完整 JSON 备份中。

### 设置提醒

在设置中选择课程提前时间并开启通知；添加个人安排时可以单独开启提醒。首次发现提醒权限未完整开启时，首页会显示一次黄色提示；进入提醒设置查看后，该提示会自动记住并隐藏，不会因你选择不使用准时提醒而反复出现。提醒依赖手机系统权限和厂商的后台策略，建议在自己的手机上用近期安排测试一次。

### 更换背景

打开设置，选择“自定义背景图”，再调节遮罩浓度和模糊程度。课表的空白位置会透出背景；恢复默认背景只会删除本地背景和外观设置，不会删除课程。

### 添加桌面小组件

在安卓桌面长按空白位置，选择“小组件”，找到“下节啥课”并拖到桌面。组件会显示下一项学校课程或个人安排，包括课程名、上课日期、开始时间、地点和距离上课的时间；没有课表时会提示打开应用导入。点击组件可以直接进入应用。

组件只读取应用保存在本机的课表，不访问网络。导入课表、修改个人安排、重启手机或系统时间变化后会刷新；安卓桌面通常还会按系统允许的周期自动刷新倒计时，倒计时显示可能存在几分钟误差。

## 导入课表

### 通用文件导入

推荐使用带有以下列的表格：

~~~text
课程名称, 星期, 节次, 周次, 教师, 教室
计算机网络, 星期二, 1-2, 1-17, 示例教师, 六教306
~~~

支持连续周、单双周和离散周次，例如 1-17、1-18单周、1,3,8-10。导入预览会显示有效记录、未识别记录、最大周次和时间冲突；解析失败或缺少上课安排的记录不会被悄悄转换成整学期课程。

示例模板和模拟 URP 文件位于 [examples/](examples/)。仓库中的示例不含个人资料，也不是学校真实课表。

### 烟台大学官网导入

当前适配烟台大学统一身份认证、eHall 办事服务大厅和本科教务系统的“选课结果”页面：

1. 点击“导入 → 烟台大学教务系统”。
2. 按学校正常流程输入账号、密码和验证码；应用不代填，也不保存账号密码。
3. 登录后进入“本科教务系统 → 选课结果”，等课程卡片完全出现，再点击“读取课表”。
4. 核对导入预览，确认后保存。

官网读取需要手机能访问学校网络。普通流量无法打开时，请连接校园网或学校 VPN。应用只读取课表，不执行选课、退课或其他教务操作；登录窗口关闭时会清理应用内的学校 Cookie、缓存和网页存储。

如果官网页面版本变化、验证码不兼容或暂时无法访问，可以在电脑登录“选课结果”页面后保存完整 HTML，再把 .html 文件导入应用。PDF、图片和扫描件目前不能直接识别，需要先人工转换并校对为表格或 HTML。

## 隐私和数据安全

- 没有广告 SDK、统计服务器、账号系统或自建后端。
- 已保存课表、个人安排、提醒和背景图存放在应用私有目录。
- 官网导入只在用户点击读取时访问学校固定 HTTPS 地址，登录信息不写入课表和备份。
- 完整备份是用户主动导出的 JSON 文件，请自行保管；它可能包含课程、地点、备注和提醒信息。
- 卸载或清除应用数据前，请先导出完整备份。换机时可用备份恢复。

## 目前支持范围

| 类型 | 当前状态 |
| --- | --- |
| 通用表格/HTML/JSON | 已支持，推荐使用标准列或示例模板。 |
| 烟台大学 URP/eHall | 已接入，仍需校园网或学校 VPN，官网读取标记为测试功能。 |

不同学校的统一认证、验证码、教务平台和课表字段差异很大。项目会把学校入口和解析规则逐步拆成独立适配器，优先保证登录范围受控、数据只读、失败时不覆盖原课表。

提交官网问题时，请删除姓名、学号、课程隐私、Cookie、验证码、密码和完整登录页面。不要把个人课表、账号信息或 .jks 签名文件提交到仓库。新学校适配建议遵循以下边界：

1. 明确允许访问的 HTTPS 主机和入口，不接受任意 URL。
2. 只读取用户主动打开的课表页面，不自动选课或退课。
3. 优先使用公开的只读接口，接口不可用时再解析页面或导入 HTML。
4. 为解析规则配套脱敏 fixture 和测试，学校页面变化时能及时发现。

欢迎先提 Issue 讨论方案，再提交 Pull Request。即使暂时不会写代码，提供一次清晰的使用反馈也很有帮助。

## 开发和构建

项目由 Java 原生 Android 外壳和随包打包的 HTML/CSS/JavaScript 界面组成。课表页面不依赖远程网页；只有官网导入需要联网。第三方依赖说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

已验证环境：Windows 11、JDK 25、Gradle 9.1.0、Android Gradle Plugin 9.0.1、Android SDK Platform 36、Build Tools 36.0.0。Node.js 24 用于测试和开发预览。

安装 JDK 和 Android SDK 后，在项目根目录执行：

~~~powershell
.\scripts\build.ps1 -SdkPath '你的 Android SDK 目录' -JavaPath '你的 JDK 目录'
~~~

脚本默认生成 debug APK 到被 Git 忽略的 dist/；发布正式包时使用 -Release。发布构建前，复制 keystore.properties.example 为 keystore.properties，填写自己的 keystore 路径、别名和密码。签名文件、密码和 keystore.properties 不会提交到仓库；release keystore 丢失后将无法继续覆盖升级旧版本。

常用开发命令：

~~~powershell
npm.cmd ci
npm.cmd test
npm.cmd run test:ui
npm.cmd run test:visual
npm.cmd run format:check
~~~

本地预览可执行 node scripts/serve.cjs，地址为 http://127.0.0.1:4173。完整验证记录见 [docs/VERIFICATION.md](docs/VERIFICATION.md)。

## 已知限制和后续方向

- 官网平台会改版，烟台大学入口和其他学校适配都需要持续验证。
- 官网读取、通知准时性和后台调度会受到校园网、WebView、系统权限和厂商省电策略影响。
- PDF/图片识别、后台同步和多学期仍在计划中。
- 课程名称过长时，首页卡片会按手机宽度截断；点击详情或列表可以查看完整内容。

后续会优先完善学校适配器、导入失败提示、提醒可靠性和无障碍体验。欢迎通过 Issue 告诉我你最需要的功能或希望支持的学校。
