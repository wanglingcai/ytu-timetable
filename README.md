# 下节啥课

一个面向安卓手机的个人课表：导入教务系统导出的文件，或在学校官网登录后读取课表，在手机本地保存，打开即可离线查看，支持切换周次和个人安排。应用不加载广告、不需要自建服务器；查看已保存课表和本地提醒无需登录或联网。0.2.0 增加联网权限，仅官网登录导入需要网络；0.4.0 增加通知、精确闹钟、开机恢复和振动权限，不申请通讯录权限。

原名“烟大随课”，从 0.1.2 起更名为“下节啥课”，适用于使用受支持课表格式的不同学校。包名、存储结构与备份格式保持兼容，旧版课表和 JSON 备份可以继续使用。

> **当前交付是 0.6.0 测试版。** 新增鲜亮蓝色渐变主题、8 组课程配色和自定义背景图；支持遮罩、模糊及自动毛玻璃显示，并修复课程标题与地点重叠。保留下一节倒计时、个人安排、安卓到点通知、文件/备份导入和烟台大学 URP 官网读取。用户已反馈 0.2.2 官网读取恢复正常；开发侧未使用真实账号独立复现，拼图验证显示仍待确认。当前 APK 不能直接导入 PDF。本应用为个人项目，非学校官方应用。

## 安装与使用

- 最新安装包：[deliverables/next-class-0.6.0-debug.apk](deliverables/next-class-0.6.0-debug.apk)，约 2.1 MB；同目录有 SHA-256 校验文件。使用相同包名和签名，可直接覆盖旧版，保留本地课表，不用先卸载。
- 手机要求：Android 8.0 及以上，使用较新版本的 Android System WebView / Chrome（建议 100 及以上）。开发侧安卓验证环境为 Android 15 模拟器；0.2.2 官网读取已获用户手机成功反馈，0.6.0 背景与新版界面、提醒尚待实体手机试用。
- 把 APK 发到手机并打开，按系统提示允许该文件管理器安装应用，安装后打开“下节啥课”。这是用于个人安装测试的 debug 签名包，未发布到应用商店。

基本流程：

首次试用可导入 [课程清单模板.csv](examples/课程清单模板.csv)，或在应用空态点击“先体验示例课表”。示例仅用于体验，需要自行导入真实课程并校对学期设置。

1. 从教务系统导出课表并保存到手机。如果只有 PDF，请先转换、校对为下列受支持的表格格式；直接选择 PDF 暂不支持。
2. 打开应用，点击右上角“导入”或空态“导入我的课表”，选择“从文件或备份导入”。文件上限 12 MB，支持 `.xlsx`、`.xls`、`.csv`、`.tsv`、`.html`、`.htm`、本应用导出的 `.json` 备份。
3. 在导入预览中核对课程、节次、周次、教师和教室。解析失败的记录会明确提示，不会自动变成整学期课程；重复记录会去重。
4. 填写学期名称、**第一周周一的日期**和学期总周数。首次默认日期为当前所在周的周一，仅为待确认的初始值，不代表学校校历。默认时间参考烟台大学课表页面，仍应按自己的校区和实际作息核对；点击设置可修改或增减节次。
5. 勾选校对确认，保存到手机。后续打开直接读取本地课表，用左右箭头或下拉菜单切换周次，点击“回到本周”返回当前周。

普通文件或官网导入保存会替换学校课程；第一周周一日期相同时保留个人安排。日期改变且有原学期个人安排时，会确认移除，取消则不修改数据。JSON 备份导入会恢复备份中的完整数据，替换当前课程和个人安排。替换、卸载或清除应用数据前，可点击“导出备份”保存 JSON。

### 日常查看

- 顶部“接下来”显示从手机当前时间算起最近一项课程或个人安排；已有安排正在进行时显示“此刻”。卡片包含开始/结束时间、地点和倒计时，点击定位实际发生日期的详情。切换浏览其他周不会改变这张卡片所依据的真实时间；界面在前台每 30 秒更新，跨日或回到前台时刷新日期。
- 周视图用蓝色表头胶囊和浅青色渐变标出今天，细线标出当前时间，仅在包含今天的周和作息范围内出现；课间停在下一节起点。非本周学校课程使用浅灰底和虚线框；本周课程按名称固定分配 8 组鲜亮配色。
- 网格标题最多显示 3 行，地点独立放在底部，过长时省略。高度不足的单节或堆叠卡片优先减少标题行数，再隐藏状态或地点，避免文字重叠与半行切断。仅网格显示时隐藏学校课程名末尾的 `_数字` 教学班后缀；详情、列表、备份与原始数据保留完整名称，个人安排名称不清洗。
- 底部固定“全部安排／＋ 添加／导出备份”，滚动后仍可使用。空课表也可以从“＋ 添加 → 个人安排”开始使用。导入入口统一在右上角；设置保留在齿轮入口。
- 页面提供轻微按压和切周过渡，遵循系统“减少动态效果”偏好。手机版编辑面板从底部展开，字段单独滚动，保存按钮保留在底部；已验证 Android 15 模拟器真实软键盘弹出后的布局。

### 自定义背景图与毛玻璃

1. 点击右上角齿轮，在“自定义背景图”选择“从相册或图片文件选择”，通过安卓系统选择器选图，无需申请全盘文件或相册访问权限。
2. 调整白色遮罩 **0%–80%（默认 35%）**、背景模糊 **0–20px（默认 0px）**，改动会自动保存，无需点击底部“保存设置”。遮罩越高图片越淡；“恢复默认背景”删除本地图片并恢复这两项默认值。
3. 有背景时，周次栏、课表外框与底部操作栏自动切换半透明毛玻璃。课程卡片保留清晰色底，日期和时间额外加衬底及深色文字；不支持毛玻璃的内核使用更实的课表底色。无背景时使用默认浅蓝白界面。

图片上限 12 MB，宽高均不得超过 20000 像素；安卓端先采样缩小到最长边不超过 2048 像素，按照片方向旋转，透明部分铺白，重新编码为 JPEG，源元数据不保留。支持设备能够解码的图片，失败时保留原背景，建议优先 JPG、PNG 或 WebP。

安卓图片和外观配置单独保存在应用私有目录，浏览器预览使用 IndexedDB 保存图片、localStorage 保存参数，均不会上传。背景不包含在 JSON 课表备份中，导入或清空课表不更换背景；卸载、清除应用数据或换机后需重新选图。浏览器预览与安卓数据互相独立。

### 点击空白格添加个人安排

1. 在周视图切换到需要安排的周，点击无课程的空白格；自动填入该星期、节次和所选周。
2. 底部面板显示日期、星期和节次。填写安排名称，可添加地点；“添加备注”展开后支持最多 2000 字。修改节次后保存，例如在周日第 5–6 节安排“图书馆自习”。
3. 默认“仅本周”；“每周”覆盖本学期全部周次，“自定义”可填 `8-10`、`1-18单周` 或 `3,8-10`。修改已有记录时保留原周次、备注和提醒选项；取消不会保存草稿。个人安排在其他周隐藏，学校课程继续保留非本周灰色显示。
4. 点击安排卡片查看、修改或删除。底部“＋ 添加 → 个人安排”也可添加，适用于列表视图或已有灰色课程的时段；“全部安排”可找到其他周的记录。删除重复安排会删除该条记录的所有周次。

个人安排随课表保存在本机，包含在 JSON 备份中。当前按课表节次安排时间，尚无任务完成勾选或任意时刻日程。备份仍使用 schemaVersion 1，个人记录增加可选的 `kind: "personal"`、`notes` 字段；旧课程备份可继续导入。

### 课程与个人安排提醒

1. 点击右上角设置，在“提醒设置”选择课程统一提前时间：默认 10 分钟，也可选准点、提前 5／15／30 分钟或关闭，点击“保存设置”。旧课表或旧备份未设置提醒时，默认课程提前 10 分钟。
2. 在设置点击“开启通知”，允许安卓通知权限；如显示“开启准时提醒”，点击并在系统页面允许“闹钟和提醒”，返回应用查看权限状态和下一次提醒时间。未允许准时提醒时使用系统可延迟调度，界面会明确提示；通知权限或通知频道关闭时不安排通知。
3. 个人安排默认不提醒。在添加或修改安排时单独选择“提醒”，可用相同时间选项；关闭课程提醒不会关闭个人安排提醒。
4. 到点显示“接下来：模拟数学”和“08:00 · A101”等信息，点击通知定位实际日期所在周的对应详情；应用已经打开或关闭界面时均可使用。声音和振动由系统通知频道、静音和勿扰设置决定。

提醒使用安卓原生 `AlarmManager`，不需要保持课表页面打开或联网。按第一周日期、实际周次、星期、开始节次和手机当地时区计算；灰色非本周课程不会提前触发，重复安排在其对应周继续提醒。一次只调度最近一批提醒，同刻多条均发送，触发后自动安排下一批。修改、删除、清空、导入课表或改变提醒设置后，撤销旧闹钟和已显示通知并重新计算；重启、应用更新、系统时间或时区变化后重算。

保存、重新启用或重启时，已过提醒时间的安排不补发。系统延迟送达的已调度提醒最多容许迟到 15 分钟，且开始超过 5 分钟后不再显示。未开准时提醒权限、厂商后台限制或省电策略可能造成延迟或错过；系统“强行停止”或冻结后需重新打开应用恢复调度。建议先在自己的手机用近期个人安排试验。

浏览器预览仅保存提醒设置，不发送后台通知。JSON 备份包含 `reminders.courseMinutes` 和个人安排的可选 `reminderMinutes`，值为 `-1`（关闭）、`0`、`5`、`10`、`15`、`30`；通知权限不随备份迁移。含提醒设置的备份请用 0.4.0 及以上版本恢复；旧版会丢弃提醒字段，0.3.0 之前还会丢弃个人安排类型和备注。

### 烟台大学官网登录导入（测试）

1. 在安卓应用点击“导入 → 烟台大学教务系统”。打开学校教务系统，按学校正常流程自行输入账号、密码和验证码。
2. 登录成功后点击窗口上方的“选课结果”，等待课表完全加载，再点“读取课表”。应用优先使用当前学校登录会话查询完整的已排课安排；接口不可用时尝试网页提取，并短暂等待异步加载。失败时显示具体原因和代码，可选“刷新页面”后重试。这一步只读取当前学期课表，不操作选课或退课，不需要先导出 PDF。
3. 应用返回现有导入预览，核对课程、教师、地点、周次、学期第一周日期和节次时间，勾选确认后保存。取消、空课表或读取失败都不会覆盖已有课表。
4. 此后可离线查看。学校调课后需重新登录读取；当前不提供后台同步、自动登录或多学期选择。

官网入口使用 `https://jwxs.ytu.edu.cn/student/courseSelect/courseSelectResult/index`，允许正常跳转到 `https://cas.ytu.edu.cn` 统一认证。独立官网窗口的主页面仍只允许这两个主机的标准 HTTPS 连接；0.2.1 另外允许学校使用的网易易盾 HTTPS 验证码脚本、图片及验证接口作为子资源加载，不替用户完成拼图验证。不开放本地课表存储桥接接口。应用不主动保存账号密码；正常关闭该窗口时清理应用内官网 Cookie、缓存与这两个学校站点的网页存储。课表备份不包含登录信息。如果学校启用了其他认证域名或不兼容 WebView 的验证方式，当前版本可能仍需适配。

0.2.1 的读取脚本去掉较新的 JavaScript 语法及 `Array.at()` 依赖，支持同源嵌入页面和没有固定卡片类名的表格段落，并处理手机换行的星期表头。已用模拟页面验证这些兼容分支；这不代表所有旧版 WebView 均受支持，仍建议更新 Android System WebView / Chrome 至较新版本。

0.2.2 使用官网选课结果页面已有的只读 GET 接口 `https://jwxs.ytu.edu.cn/student/courseSelect/thisSemesterCurriculum/callback`。只在点击“读取课表”后发起查询，登录会话仅用于这次固定学校主机的 HTTPS 请求，不记录到日志或课表备份，不向第三方服务器发送。接口返回的培养方案等附加字段不进入课表；仅转换课程名、课序、教师、星期、节次、周次和地点。有课程缺少明确上课安排时提示另行核对，不擅自补成整学期。响应结构转换与预览已用模拟响应验证，用户随后反馈读取恢复正常；开发侧未取得真实登录接口响应，该反馈不能代表所有设备或学校页面版本。

也可以在电脑登录后的“选课结果”页面按 Ctrl+S 保存完整 HTML，将 `.html` 主文件发到手机，使用“导入课表”读取；配套 `_files` 目录无需发到手机。已验证一份真实网页中的 14 条上课安排、13 个课程名称及全部教师、地点、节次与周次，与先前人工核对文件逐项一致。这里只证明该样本，不能保证所有 URP 版本或未来页面结构都兼容。官网提示“有课程未显示”时，导入预览会提示另行核对。

## 已实现功能

- **鲜亮主题与本地背景**：蓝色渐变预告卡和添加按钮、8 组按名称固定的课程色、灰色虚线参考课；本地选图、遮罩、模糊、毛玻璃和恢复默认。
- **烟台大学官网读取入口（测试）**：手动登录后优先查询官网课表数据，网页提取作为备用，均进入同一核对预览；缺少可解析安排时不会保存空课表。真实保存网页解析已验证，0.2.2 已获得用户手机读取成功反馈。
- **个人安排**：点击空白格添加自习、运动或待办安排，支持地点、多行备注、单周或重复周次，点击卡片修改/删除；同学期重新导入学校课表时保留。
- **日常首页与添加面板**：最近/进行中的安排、倒计时、真实日期跳转、今天列与时间线；固定加号、底部编辑、快捷周次及备注展开。保持原有 JSON 格式与本地数据兼容。
- **到点提醒**：课程统一设置提前时间，个人安排独立设置；按实际日期和周次发安卓通知，点击打开详情，课表变更同步取消旧提醒。权限和下一次调度时间可在设置查看。
- **周视图和列表视图**：本周课程正常着色，非本周课程以灰色显示并标注“非本周”，点击仍可查看实际上课周次；支持手动添加、修改和删除。
- **本周与参考安排区分**：本周课程数和冲突提示只统计实际在所选周上课的记录；同一时段的本周/非本周安排上下显示，本周卡片位于上方并保留更多空间。所选周完全无课时仍保留灰色参考卡片。
- **周次处理**：连续周、单双周、指定周、离散周次，例如 `1-17`、`1-18单周`、`第3周`、`1,3,8-10`；支持 1–60 周、1–16 节。
- **两种表格结构**：带课程/星期/节次/周次等列的课程清单，以及带星期列、节次行、合并单元格的 URP 风格周课表网格。
- **导入预览**：显示有效记录、最大周次、未识别记录和时间冲突；时间冲突的课程全部保留并在周视图中分列显示。
- **本地持久化**：安卓端使用应用私有目录中的 `timetable.json`，通过 `AtomicFile` 写入；修改成功后才能更新界面。浏览器预览使用 `localStorage`，与安卓端数据互相独立。
- **本地备份恢复**：安卓端通过系统文件选择器导入和选择备份保存位置，不需要申请全盘文件访问权限。应用关闭系统云备份和设备转移，跨设备迁移请使用显式导出的 JSON。
- **明确的边界**：默认空课表，体验示例需要主动点击并确认，所有示例均标注为模拟数据。

## 示例与表格要求

[examples/](examples/) 包含可用于试用和填写的文件：

- `课程清单模板.xlsx`、`课程清单模板.csv`：标准列为 `课程名称,星期,节次,周次,教师,教室`。
- `模拟URP网格.xlsx`、`模拟URP网格.xls`、`模拟URP网格.html`：用于测试合并单元格和 URP 风格课表，**均非学校真实导出文件**。
- `模拟URP官网.html`：模拟官网的段落课程卡片、同格多门课程、合并行及“课程未显示”提示，不含真实个人资料。

GitHub 仓库仅包含程序、安装包、模拟示例与通用验证记录。原始个人 PDF、转换后的个人课表、专用转录脚本和个人核对记录通过 `.gitignore` 保留在本机，不上传至仓库。本机根目录已保存的 `URP高校教学管理与服务平台（学生）.html`、`选课结果.html` 及对应 `_files/` 配套资源目录也已忽略；后续教务网页样本统一放在已忽略的 `tmp/` 目录，避免个人资料随代码提交。

CSV 示例（逗号分隔；周次字段包含逗号时需要双引号）：

```csv
课程名称,星期,节次,周次,教师,教室
计算机网络,星期二,1-2,1-17,示例教师,六教306
单周课程,星期四,1-2,1-18单周,示例教师,六教306
离散周课程,星期五,7-8,"1,3,8-10",示例教师,实验室2
```

网格中的课程信息按“课程名称、教师、周次、节次、教室”的文本顺序解析；单元格允许包含多条上课安排。无法识别的格式会在预览提示。工作簿会检查所有工作表，因此请只导出一个学期，避免把不同学期放在同一文件。

## 开发环境与构建

应用使用 Java 原生安卓外壳与随包打包的 HTML/CSS/JavaScript 界面；Excel 解析库为 SheetJS CE 0.20.3，图片方向读取使用 AndroidX ExifInterface 1.4.2。课表界面没有远程网页依赖；独立的官网登录导入窗口需要访问学校网站。第三方说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

已验证构建环境：Windows 11、JDK 25、Gradle 9.1.0、Android Gradle Plugin 9.0.1、Android SDK Platform 36、Build Tools 36.0.0。Node.js 24 仅用于测试和开发预览。构建时需要联网下载依赖；应用离线查看和文件导入不需要联网，官网登录导入需要联网。

安装好 JDK 和 Android SDK、接受对应 SDK 许可后，在项目根目录执行：

```powershell
.\scripts\build.ps1 -SdkPath '你的 Android SDK 目录' -JavaPath '你的 JDK 目录'
```

脚本会配置本机 `local.properties`、执行构建与 Lint、根据 `app/build.gradle` 的版本号命名 APK，复制到 `deliverables/` 并为目录中的所有 APK 生成 SHA-256 校验文件。也可使用 `ANDROID_HOME` 指定 SDK，并直接运行：

```powershell
.\gradlew.bat :app:assembleDebug :app:lintDebug
```

当前工作区的工具位于忽略提交的 `.tools/`。在此工作区运行 `scripts/build.ps1` 可自动使用 `.tools/android-sdk`；其他机器需自行安装 SDK。Gradle Wrapper 包含官方分发包 SHA-256 校验，`package-lock.json` 固定测试依赖。

开发预览与测试：

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run test:ui
node scripts/serve.cjs
```

预览地址为 `http://127.0.0.1:4173`。浏览器测试使用本机 Microsoft Edge；其他系统可在 `playwright.config.cjs` 中调整浏览器配置。重新生成示例文件使用 `npm.cmd run fixtures`。

Android 原生冒烟测试在**专用模拟器**安装主 APK 和测试 APK，然后运行自定义 Instrumentation；测试需要初始空数据，会导入模拟课程。完整命令与已验证结果见 [docs/VERIFICATION.md](docs/VERIFICATION.md)，不要对有真实课表数据的手机执行清空测试命令。

## 当前限制与下一步

- **PDF 处理范围**：已在本地核对过一份实际图片型 PDF，并验证其人工转换 CSV 的导入。仓库不提供个人课程数据，也不是通用 PDF 解析器；新的 PDF 仍需要识别、校对和转换。
- 暂不支持教务系统自动登录/后台同步、PDF/图片识别、桌面小组件或多学期切换；学校调课后需要重新读取官网或导入文件。提醒已在 Android 15 模拟器验证，实体手机和厂商省电策略下的准时性待验证。
- 未安排周次/时间的课程不会显示到周视图；请按导入提示人工核对、必要时手动补充安排。课程名/地点较长时，手机周视图会截断，点击详情或切换列表可查看全文。
- 旧版 WebView、加密或损坏的工作簿、非标准网格仍可能无法解析；没有“所有高校文件都兼容”的保证。
- 当前 APK 为 debug 签名；后续覆盖安装需要使用相同签名。更换构建机器或签名、卸载重装前，请先备份。
