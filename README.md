# 下节啥课

一个面向安卓手机的个人离线课程表：导入教务系统导出的课表，在手机本地保存，打开即可查看，支持切换周次。应用不加载广告、不需要登录、不申请联网或通讯录权限，也不需要自建服务器。

原名“烟大随课”，从 0.1.2 起更名为“下节啥课”，适用于使用受支持课表格式的不同学校。包名、存储结构与备份格式保持兼容，旧版课表和 JSON 备份可以继续使用。

> **当前交付是文件导入测试版。** 支持 Excel、CSV、HTML 和本应用 JSON 备份；**当前 APK 不能直接导入 PDF**。图片型 PDF 需要先识别、校对并转换为受支持的课表格式，自动 PDF/OCR 导入尚未实现。本应用为个人项目，非学校官方应用。

## 安装与使用

- 最新安装包：[deliverables/next-class-0.1.2-debug.apk](deliverables/next-class-0.1.2-debug.apk)，约 1.3 MB；同目录有 SHA-256 校验文件。使用相同签名，可直接覆盖安装 0.1.0 / 0.1.1，保留已保存课表；不用先卸载。
- 手机要求：Android 8.0 及以上，使用较新版本的 Android System WebView / Chrome（建议 100 及以上）。当前安卓验证环境为 Android 15 模拟器，尚未在用户实体手机上测试。
- 把 APK 发到手机并打开，按系统提示允许该文件管理器安装应用，安装后打开“下节啥课”。这是用于个人安装测试的 debug 签名包，未发布到应用商店。

基本流程：

首次试用可导入 [课程清单模板.csv](examples/课程清单模板.csv)，或在应用空态点击“先体验示例课表”。示例仅用于体验，需要自行导入真实课程并校对学期设置。

1. 从教务系统导出课表并保存到手机。如果只有 PDF，请先转换、校对为下列受支持的表格格式；直接选择 PDF 暂不支持。
2. 打开应用，点击“导入课表”，选择该文件。文件上限 12 MB，支持 `.xlsx`、`.xls`、`.csv`、`.tsv`、`.html`、`.htm`、本应用导出的 `.json` 备份。
3. 在导入预览中核对课程、节次、周次、教师和教室。解析失败的记录会明确提示，不会自动变成整学期课程；重复记录会去重。
4. 填写学期名称、**第一周周一的日期**和学期总周数。首次默认日期为当前所在周的周一，仅为待确认的初始值，不代表学校校历。默认时间参考烟台大学课表页面，仍应按自己的校区和实际作息核对；点击设置可修改或增减节次。
5. 勾选校对确认，保存到手机。后续打开直接读取本地课表，用左右箭头或下拉菜单切换周次，点击“回到本周”返回当前周。

导入保存会替换现有课表。替换、卸载或清除应用数据前，可点击“导出备份”保存 JSON；之后用“导入课表”重新导入该 JSON，恢复学期设置、作息时间和课程。

## 已实现功能

- **周视图和列表视图**：本周课程正常着色，非本周课程以灰色显示并标注“非本周”，点击仍可查看实际上课周次；支持手动添加、修改和删除。
- **本周与参考安排区分**：本周课程数和冲突提示只统计实际在所选周上课的记录；同一时段的本周/非本周安排上下显示，本周卡片位于上方并保留更多空间。所选周完全无课时仍保留灰色参考卡片。
- **周次处理**：连续周、单双周、指定周、离散周次，例如 `1-17`、`1-18单周`、`第3周`、`1,3,8-10`；支持 1–60 周、1–16 节。
- **两种表格结构**：带课程/星期/节次/周次等列的课程清单，以及带星期列、节次行、合并单元格的 URP 风格周课表网格。
- **导入预览**：显示有效记录、最大周次、未识别记录和时间冲突；时间冲突的课程全部保留并在周视图中分列显示。
- **本地持久化**：安卓端使用应用私有目录中的 `timetable.json`，通过 `AtomicFile` 写入；修改成功后才能更新界面。浏览器预览使用 `localStorage`，与安卓端数据互相独立。
- **本地备份恢复**：安卓端通过系统文件选择器导入和选择备份保存位置，不需要申请全盘文件访问权限。应用关闭系统云备份和设备转移，跨设备迁移请使用显式导出的 JSON。
- **明确的边界**：默认空课表，体验示例需要主动点击并确认，所有示例均标注为模拟数据。

## 示例与表格要求

[examples/](examples/) 包含可用于试用和填写的文件：

- `课程清单模板.xlsx`、`课程清单模板.csv`：标准列为 `课程名称,星期,节次,周次,教师,教室`。
- `模拟URP网格.xlsx`、`模拟URP网格.xls`、`模拟URP网格.html`：用于测试合并单元格和 URP 风格课表，**均非学校真实导出文件**。

GitHub 仓库仅包含程序、安装包、模拟示例与通用验证记录。原始个人 PDF、转换后的个人课表、专用转录脚本和个人核对记录通过 `.gitignore` 保留在本机，不上传至仓库。

CSV 示例（逗号分隔；周次字段包含逗号时需要双引号）：

```csv
课程名称,星期,节次,周次,教师,教室
计算机网络,星期二,1-2,1-17,示例教师,六教306
单周课程,星期四,1-2,1-18单周,示例教师,六教306
离散周课程,星期五,7-8,"1,3,8-10",示例教师,实验室2
```

网格中的课程信息按“课程名称、教师、周次、节次、教室”的文本顺序解析；单元格允许包含多条上课安排。无法识别的格式会在预览提示。工作簿会检查所有工作表，因此请只导出一个学期，避免把不同学期放在同一文件。

## 开发环境与构建

应用使用 Java 原生安卓外壳与随包打包的 HTML/CSS/JavaScript 界面；Excel 解析库为 SheetJS CE 0.20.3。运行时没有远程网页依赖。第三方说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

已验证构建环境：Windows 11、JDK 25、Gradle 9.1.0、Android Gradle Plugin 9.0.1、Android SDK Platform 36、Build Tools 36.0.0。Node.js 24 仅用于测试和开发预览。构建时需要联网下载依赖，应用使用时不需要联网。

安装好 JDK 和 Android SDK、接受对应 SDK 许可后，在项目根目录执行：

```powershell
.\scripts\build.ps1 -SdkPath '你的 Android SDK 目录' -JavaPath '你的 JDK 目录'
```

脚本会配置本机 `local.properties`、执行构建与 Lint、根据 `app/build.gradle` 的版本号命名 APK，复制到 `deliverables/` 并为目录中的所有 APK 生成 SHA-256 校验文件。也可使用 `ANDROID_HOME` 指定 SDK，并直接运行：

```powershell
.\gradlew.bat :app:assembleDebug :app:lintDebug
```

当前工作区的工具位于忽略提交的 `.tools/`。在此工作区运行 `scripts/build.ps1` 可自动使用 `.tools/android-sdk`；其他机器需自行安装 SDK。Gradle Wrapper 包含官方分发包 SHA-256 校验，`package-lock.json` 固定测试依赖。

开发预览与测试：

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run test:ui
node scripts/serve.cjs
```

预览地址为 `http://127.0.0.1:4173`。浏览器测试使用本机 Microsoft Edge；其他系统可在 `playwright.config.cjs` 中调整浏览器配置。重新生成示例文件使用 `npm.cmd run fixtures`。

Android 原生冒烟测试在**专用模拟器**安装主 APK 和测试 APK，然后运行自定义 Instrumentation；测试需要初始空数据，会导入模拟课程。完整命令与已验证结果见 [docs/VERIFICATION.md](docs/VERIFICATION.md)，不要对有真实课表数据的手机执行清空测试命令。

## 当前限制与下一步

- **PDF 处理范围**：已在本地核对过一份实际图片型 PDF，并验证其人工转换 CSV 的导入。仓库不提供个人课程数据，也不是通用 PDF 解析器；新的 PDF 仍需要识别、校对和转换。
- 暂不支持教务系统自动登录/同步、PDF/图片识别、提醒、桌面小组件或多学期切换；学校调课后需要重新导出并导入。
- 未安排周次/时间的课程不会显示到周视图；请按导入提示人工核对、必要时手动补充安排。课程名/地点较长时，手机周视图会截断，点击详情或切换列表可查看全文。
- 旧版 WebView、加密或损坏的工作簿、非标准网格仍可能无法解析；没有“所有高校文件都兼容”的保证。
- 当前 APK 为 debug 签名；后续覆盖安装需要使用相同签名。更换构建机器或签名、卸载重装前，请先备份。
